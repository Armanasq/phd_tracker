# Accessibility

PhD Atlas targets WCAG 2.2 Level AA. Automated tests are development controls, **not a certified conformance declaration**.

The public application uses labelled native controls, keyboard navigation, a skip-to-content link, accessible modal focus handling, responsive application cards, and visible verification states. The source inventory is available as text and tables rather than only as visual charts. Verification checks are filterable and progressively displayed, with a complete CSV export.

Repository browser workflows include route coverage and automated accessibility checks. Manual screen reader testing, assistive-technology validation and comprehensive WCAG review remain outstanding.

Report reproducible barriers using the [issue template](https://github.com/Armanasq/phd_tracker/issues/new?template=04-bug-report.yml) and include route, browser, assistive technology (if relevant), keyboard sequence and actual behavior. Do not include private applicant information in public issues.
