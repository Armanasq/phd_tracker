# Contributing

## Scope

Contributions may improve the PhD Atlas frontend, source-verification pipeline, deterministic decision support, private AI adapters, tests or documentation. Do not treat an unverified job listing, email excerpt or inferred funding amount as an authoritative fact.

## Development

1. Fork or create a feature branch from `main`.
2. Install the dependencies: `python -m pip install -r requirements-intelligence.txt`.
3. Rebuild the source projection: `python scripts/build_workspace.py --out site/data/workspace.json`.
4. Run the tests: `python -m pytest tests -q` and `node --test tests/domain.test.mjs`.
5. Validate browser modules with `node --check site/app.js` and `node --check site/modules/lens.mjs`.
6. If you changed interaction or layout code, review the GitHub Actions browser smoke and accessibility results before merging.

The full browser tests require Playwright and Chromium; `.github/workflows/visual-qa.yml` provisions them.

## Evidence changes

Attach the official source URL, observation date and exact quoted requirement or deadline; separate primary evidence from deductions and manual owner updates. Preserve unverified states, contradictions, expired/blocked routes and duplicate-submission warnings. Never fabricate a source, faculty commitment, exact cutoff time, eligibility decision or submission receipt.

## Documentation

`README.md` is the concise product entry point and is generated by `scripts/render_command_center.py`. `docs/RESEARCH_REPORT.md` contains the expanded, automatically generated research and operations report. Do not hand-edit generated report content without updating its source generator.

## Privacy

Keep credentials, owner-specific private SQLite state, personal communication and unaudited candidate materials out of committed sources. See [SECURITY.md](SECURITY.md).
